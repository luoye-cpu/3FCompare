# 128-启动压进 1000ms：分账与执行计划（2026-10-31）

> 阶段性目标：**`Process.Start → 首帧上屏` ≤ 1000 ms**。
> 本文先给可执行的分账（全部来自同一批对齐数据），再给逐项动作与判据。
> 口径统一：**[LT] 里程碑用绝对 QPC，减去 `Process.Start` 前的 QPC** ⇒ 与 T2 同一原点。

**T2=1384.8**（n=10，spawn 7.2 ms，全程 fast 档）同一量级。取保守基线 **1654 ms**。

## 2. 两件结构性的事（这才是能不能进 1000 的关键）

### 2.1 开图提前到 Shown 之前（预计 −250…−400）

现状：`42_open_dispatched`(1467.0) 在 `40_shown_begin`(1464.4) **之后**——即窗口已显示
才开始开图。而 `51_open_media_called` 到 `73_open_done` 只要 57 ms，**开图本身不慢**。
⇒ 若把 `FFF3FP_Open` 的派发挪到 `32_load_end`(1203.7) 之后、`40_shown_begin` 之前，
则解码链（57 ms）可与"框架显示序列"（260.7 ms）**重叠**，白赚 57 ms；
若再能把 Attach 之后的宿主构建与开图并行，上限更多。

**但 125 §13.3 已记**："更早绑窗会不会被内核接受"**未验**。这是必须先验的一步，
已验证的只有"句柄可按需拿到"（`播放器画面控件.vb:92-96`，`.Handle` 即时建句柄）。

### 2.2 T2 判据与目标口径要对齐（否则无法验收）

`quiet_ab` 的 T2 走屏幕抓图；`[LT]` 走进程内 QPC。两者原点差 `Process.Start` 到
`00_startup_begin` 的 116.7 ms + 抓图轮询延迟。
⇒ 验收必须**同一工具**同时给 T2 与里程碑（本轮已建 `pr48_align.ps1`，但它的
T1/T2 判据还有 bug：T1 报 5 ms、T2 恒 −1，见 §4）。

## 3. 执行顺序（每步都可独立回退、都有配对判据）

| 步 | 动作 | 判据 | 预计 |
|---|---|---|---:|
| S1 | 先修 `pr48_align.ps1` 的 T1/T2 判据，得到可信的同批 T2+里程碑 | T1≈1339、T2≈1464–1660 | 0（仪表） |
| S2 | 四呈现器群延后到 `40_shown_begin` 之后 | `24→25` 段 ≤40；配对 ≥12 轮 | −140 |
| S3 | 消重复 `PerformLayout` + 合并一次 `SetWindowPos` | `30→31` ≤30 | −60 |
| S4 | 文件关联后台同步挪到 T2 之后 | `13→14` ≤10 | −30 |
| S5 | 开图派发提前（先只挪派发点，不挪绑窗） | `40_shown_begin` 不变、`73_open_done` 前移 | −57 |
| S6 | Attach 内部补 4 枚子戳，再决定是否动 LakeUI | 只测量 | 0（仪表） |

逐步做，每步 A/B 都 ≥12 轮交替配对；**低于该窗分辨水位的单步不声称**，
改按"组合臂"测（同 README 的既有约定）。

## 4. 本轮已发现的两个仪表 bug（必须记）

1. **`pr48_align.ps1` 的 T1 判据把启动早期的无客户区窗口当成了主窗** ⇒ T1 报 4.9–5.4 ms
   （真值 ~1339 ms）。修法：`IsWindowVisible` **且**标题非空 **且** `GetClientRect`
   ≥160×120（已改，但重跑仍报 5 ms ⇒ 说明还有第二处：`FindTitled` 的第一次调用发生在
   更早的时机，而未刷新 `cls/title` 的旧值）。**下一步必须先修到 T1≈1339 才能继续。**
2. `SampleClient` 返回 false 时 `$streak` 不复位、`$hwnd` 可能为 0 ⇒ T2 恒 −1。

## 5. 现状与诚实结论

- **654 ms 的缺口，靠"微优化"补不上**。可量的微项合计 350–450；
  结构性两项（开图提前、Attach）各需先验/先拆。
- 本轮**未改任何产品代码**（`3fp/kernel` `porcelain=0`、HEAD `54f3485`）。
- 已建成可复用的验收仪表：`pr48_align.ps1`（同批算 T2+里程碑）、`align_stats.py`、
  `startup_breakdown.py`、`pr48_lm_ab.ps1`（配对 A/B）。
