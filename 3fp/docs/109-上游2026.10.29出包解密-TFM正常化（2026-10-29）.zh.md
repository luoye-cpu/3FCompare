# 上游 2026.10.29 出包解密：TFM 正常化 −26.9 MB（2026-10-29）

- 触发：用户发现上游最新出包体积降到 ~10MB，要求先行分析出包脚本是怎么做到的；随后转入启动性能优化开工。
- 结论先行：**与出包脚本几乎无关（脚本只改了两行注释）——体积下降的真正开关是 `FFF.Player.vbproj` 的 TFM 一行改动**：`net10.0-windows10.0.26100.0` → 裸 `net10.0-windows`。实际新体积 **13,082,960 B（12.5 MB）**（旧 39,965,782 B，−26,882,822 B ≈ −67%）。

## 二、机制：为什么裸 TFM 能白拿 27.6 MB

1. **bundle 成分实测**（双 exe 二进制扫描对照）：新 exe 中 `Microsoft.Windows.SDK.NET` 与 `WinRT.Runtime` **双双消失**；`FFF.Native`/`ass_render`/`harfbuzz`/`avcodec-63` 引用在（原生件照旧捆绑）；`hostfxr` 在（仍是框架依赖单文件 bundle，非 AOT——PE 节表 .text 仅 99 KB，尾部 manifest 条目可见）。
2. **根因 = NuGet 资产变体选择**（本机 NuGet 缓存实扫，一锤定音）：
   - `Vortice.Mathematics 2.1.0`：`net10.0-windows10.0.19041` 变体**引用** SDK.NET+WinRT.Runtime；裸 `net10.0` 变体**干净**；
   - `Vortice.DirectX 3.8.3`：`net10.0-windows10.0.22621` 变体引用 WinRT.Runtime；裸 `net10.0` 变体干净；
   - `LakeUI.dll` 本体（HintPath 直引，非 NuGet）：两种形态都零引用。
   ⇒ 带版本号 TFM 使 NuGet 选中 WinRT 风味变体 → 投影闭包真实存在；裸 TFM 直接切纯 P/Invoke 变体 → 投影依赖连根消失，SDK 不再自动引 `Microsoft.Windows.SDK.NET.Ref`。
3. **体积对账**：−26,882,822 B ≈ SDK.NET 27.25 MB + WinRT.Runtime ~0.35 MB − 少量新增（播放列表代码等），量级闭合；逐件精确清单待 bundle 解析器修好（旧「找 32B 签名」法对 net10 SDK 产物失效——签名命中点是 apphost 内嵌补丁位，见 §五）。

## 三、旧证伪结论修正（重要）

- **docs/105 §五/§六/§十五「SDK.NET 不可剔（Vortice.Mathematics 引用闭包）」仅在 versioned-TFM restore 下成立**，不是普适结论。上游用 TFM 正常化这一**官方支持路径**把前提拆掉了。
- 护栏 `2c4be0e` 的**逻辑本身依然正确**（引用⇒随包的条件判断，不无条件要求投影存在），新形态下自然全绿；但其 vbproj 注释里「两件均不可剔」的断言已过时，值得在上游顺手更新注释（小 PR）。
- 教训入册：**「引用闭包证伪」要先问 restore 形态**——同一组包在不同 TFM 下解析出不同资产变体，闭包结论不可跨形态搬用。

## 四、对启动性能面的影响（本任务主线）

- **预期 ≈ 零变化**：SDK.NET 本来就是死重——ETW 模块时间轴从未出现它的 ImageLoad，托管件内存加载也不参与首跑解压（解压载荷是原生件 ~10.6 MB，成分不变）。
- 量化确认排入安静窗复测：多加一臂「TFM 正常化产物」两臂交替即可，顺手拿数。
- **体积-启动联动的额外红利**：我们交付已同步正常化，45,589,568 B → **实测 17,737,018 B（16.92 MB）**（我们内核含 IAMF 5.62 MB；与上游 1.02 MB 的 4.6 MB 差异已归因 = IAMF 静态闭包 4.35 MB + 内核基线差，见 docs/110）。
- **待验证风险点**：裸 TFM 下 `SupportedOSPlatformVersion` 降到 7.0、WinRT 投影 API 编译期不可用——若宿主/LakeUI 有运行时才会踩到的 WinRT 类型（懒绑定），是潜在运行时炸弹。上游已实机发布，且我们此前实测「剔除后照常工作」（docs/105 §6.3），风险低但复测时以开图+播放冒烟兜底。

## 六、陷阱追加

- `bundle_parse.py` 的「rfind 32B 签名」对 net10 SDK 单文件产物会命中 apphost 内嵌补丁位（假阳性），真 manifest 在 EOF 无签名前缀——别再按旧格式找。
- `Get-Process`/探针都受**单实例互斥**约束：任何 FFF.Player 在跑（包括其他 agent 的测试会话）都会让探针拒跑——先查实例再排测量。
