SDR 10bit / wide-gamut sources: present through 16-bit scRGB with system-anchored paper white

Kernel (API 15 -> 16; full-file drop in 3fp/patches/sdr-scrgb-kernel/, see README there):

- FFF3FPConfiguration gains `sdrScRgbMode` (0 = never, 1 = auto). FFF3FP_Create
  rejects > 1 with InvalidArgument. PlayerApiVersion 15 -> 16; VER_API synced.
- New WantsScRgbPresentationPath() collapses the three duplicated color gates
  (SetWindow / SetColorMode / EnsureSwapChain) and adds one term: an SDR source
  whose bit depth exceeds 8 now also wants the scRGB chain. Display gate
  (OutputSupportsHdr) unchanged - non-Advanced-Color desktops keep the classic
  SDR chain unchanged.
- SDR source on the scRGB chain now declares DXGI_HDR_METADATA_TYPE_NONE.
  Previously SetHdrMetadata published a fallback HDR10 block (Rec.2020
  primaries + 100-nit peak the source never claimed).
- Paper white anchoring, EffectivePaperWhiteNits(): when an SDR source is
  presented on the scRGB chain, paper white = Windows "SDR content brightness"
  (AdvancedColorInfo::SdrWhiteLevelInNits, DISPLAYCONFIG as second read) so the
  picture lands on the luminance the classic SDR chain got from DWM. Falls
  back to 80 nits (scRGB contract reference) when unreported. HDR sources keep
  the configured 200-nit graphics white. Video, subtitle overlay and cover
  tint share the resolved value.
- P3 primaries fixed: the gamut switch is now three-state (0 = Rec.709,
  1 = Rec.2020, 2 = P3) with a P3->Rec.709 linear matrix (negative components
  carried by FP16). ShaderBytecode.h regenerated with fxc - the production
  shader is precompiled DXBC, editing HLSL alone has no effect.
- No enum or exported-signature changes: FFF3FPColorMode stays 3 values,
  FFF3FP_SetColorMode signature unchanged.

Host:

- AppSettings.SdrScRgbMode (default 1 = auto, Normalize clamps to [0,1]).
- EngineSessionOptions.SdrScRgbMode -> Fff3FpConfiguration (ConfigVersion 16,
  strict-equality lockstep with the kernel).
- Settings window: new dropdown in the Color section (both deep-copy sites and
  the changed-detection chain updated); zh/en strings; applied to new sessions.
- Tests: clamp + DTO default-value contracts; full suite 728 passing.

Tooling (repo tools/):

- build_kernel_3fp.py: build 3fp/kernel/FFF.Native (the tree the app runs;
  third_party/fff_project is the upstream-PR checkout and lacks the
  wide-gamut gate - do not ship its DLL).
- build_sdr_scrgb.py: ordered driver - regenerate ShaderBytecode.h with fxc,
  flip kShaderGamutTristate, build, sync DLL.
- generate_shader_bytecode.py: HLSL -> DXBC regeneration (production shader
  never compiles HLSL at runtime).
- check_kernel_config_abi.py: FFF3FPConfiguration layout smoke test (catches
  managed/native drift that otherwise surfaces as "every session fails").
- verify_image_mode --sdr-scrgb; sdr_white_probe.cpp (V7 verdict tool).
