# 06 风险与依赖

## 1. 外部依赖清单

| 依赖 | 来源 | 版本策略 | 说明 |
| --- | --- | --- | --- |
| `FFF.Native` 源码（子模块） | [FFF_Project](https://github.com/Lake1059/FFF_Project) `FFF.Native`，**MIT 许可（已确认）** | 以 git submodule 固定 commit；基于其上追加扩展补丁（见 03 §6）；保持与上游可合并 | 核心后端：解码/渲染/时钟/字幕 |
| Shared FFmpeg DLL | [BtbN FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds/releases)（`...-win64-gpl-shared.zip`） | 固定到与上游兼容的 commit；**不与不同版本 DLL 混用** | avcodec/avformat/avutil/swresample/swscale/avfilter |
| libass | 上游 `tools/准备FFmpeg.ps1` 固定 | 随构建脚本 | ASS/SSA 字幕（MVP 可不用但发布需要） |
| .NET 11 | Microsoft | **NativeAOT 自包含单文件（已启用并验证）**；框架依赖模式备选 | 起更快、无运行时依赖；互操作层 `[LibraryImport]` + JSON 源生成上下文（JsonAotContext）已兼容 |

> FFmpeg 更新政策：允许用户整体替换目录中的一组 FFmpeg DLL 以享受新 FFmpeg 特性（3F 家族特色），
> 但需保证与 `FFF.Native` ABI 兼容（上游 README 明示）。本项目 UI 层不直接调用 FFmpeg。

## 4. 质量策略

- **自动化**：`Core.Tests`（同步换算、偏移、clamp、帧表、设置序列化）；E3 冒烟作为 CI 前置；
  可选针对 D3D/UI 的冒烟以 3FP 上游测试方式手测。
- **性能门禁**：M5 前建立基准（2/4 路 1080p 打开耗时、步进 P95、内存峰值、显存占用）。
- **兼容矩阵**：Win10 22H2 / Win11；x64 only（3FP 只出 x64）。
- **ACM/VRR 测试矩阵**：SDR 常规显示器 / 启用 ACM（广色域）/ 真 HDR 显示器 / G-SYNC 或 FreeSync 显示器；
  覆盖窗口态与全屏态；记录 `实际色彩模式`、是否触发 `色彩模式变化`、是否出现撕裂。
- **许可合规**：不包含 3F/FFmpeg 二进制仓库内；发布说明标注所需第三方 DLL 及其获取方式。

## 5. 升级与演进

- 3FP 升级：重新构建/替换 DLL → 启动校验 API 版本 → 跑回归。
- FFmpeg 升级：跟随 BtbN 新版本整体替换，跑 E3 冒烟回归。
- **显示驱动/Windows 集成更新后**：重跑 ACM/VRR 专项验收（Windows 更新可能改变 Advanced Color 行为）。
- 后续能力池（未排期）：字幕/弹幕叠加对比、多语言界面、CLI 批处理、遥测（可选）。
