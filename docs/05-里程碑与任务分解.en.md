## M0: Skeleton — 2-Stream Sync Stepping (minimal closed loop vs. ICAT)

**Goal**: open 2 videos, sync pause/single-frame step, show frame number and time; lay the foundation for later expansion.

Tasks:

1. Create the solution skeleton:
   - `src/3FCompare.App` (WinForms, .NET 11)
   - `src/3FCompare.Core/Backend`, `Core/Sync`, `Core/Compare`, `Core/Settings`, `Core/Models`
   - `tests/3FCompare.Core.Tests`
2. Minimal `Backend.3FP` interop layer (P/Invoke, not reusing managed `FFF.Player`):
   - `IPlayerEngine`: create/open/pause/stop/Seek/Step/snapshot/media info/probe
   - `EngineSession` wraps the native session handle + event-callback threading discipline (borrowing upstream managed-layer semantics)
3. `PlayerSurface` control: independent native window (Handle) + set output window; re-set output window on resize
4. `CompareGridView`: 2 streams side-by-side filling, click to select
5. Transport bar: open file, pause/play, **dual stepping (±frame/±second button sets)**, show frame number/time
6. SyncController v1: PTS baseline + `Seek` stepping (session 0 as master)
7. Fold the E3 smoke test into automated tests

**DoD**: 2 streams of 1080p opened simultaneously; arrow keys/buttons step by frame and by second, same frame; frame number/time consistent in real time; probe can read a pixel; drag-drop opens files.

## M1: 9-Stream Support & Layout

1. **1~9 PlayerSurface + grid layouts 1x1/2x1/2x2/3x2/3x3** (selection highlight)
2. Layout model `LayoutModel.Viewport` (all Surface positions/sizes updated by the render loop)
3. Per-stream offset calibration UI (±frames/±ms; "align to this frame")
4. Media info panel (resolution/frame rate/codec/color)
5. Timeline v1: multi-track scale (per-stream independent timeline + global master scale), click-to-Seek
6. Error placeholder UI for failed sessions
7. **Fullscreen/window mode switching (FullscreenController initial version)**

**DoD**: 9 streams open simultaneously and step in sync; any stream selectable, single-view; two streams frame-aligned after offset calibration; timeline drag seeks all streams; window/fullscreen switchable.

## M2: Playback Enhancements & Looping

1. Sync play/pause/stop (with auto drift correction, see 04 §3.1)
2. Playback speed: first do 0.5x/1x/2x "frame-sampling playback" (per A2 decision); use 3FP's rate API directly if available
3. Interval loop (A/B points): timeline markers, loop toggle, boundary auto-Seek
4. High-frequency snapshot polling engine (60Hz) + unified frame-number/time refresh
5. Per-stream independent volume control (audio muted by default — reviewers only watch the picture)
6. **Hardware encode/decode switch + multi-GPU selection (A11 implementation)**: global/per-stream toggle; enumerate adapters to pick a GPU per stream
7. **Frame/second step sizes adjustable at runtime (linked to settings window)**

**DoD**: sync play of 2/4 streams stays stable without drift (drift < 200ms); A/B loop smooth for repeated inspection; each stream can be muted.

### (Pre-M3 confirmation) A8/A9: VRR swap-chain capability test

- Test with the E3 smoke project: does the 3FP swap chain support `ALLOW_TEARING`/variable refresh; does Present follow media frame rate;
- **Because we forked the source**: after testing, implement `FFF3FP_SetPresentConfig` directly as a patch (see 03 §6) without waiting for upstream; write conclusions into ReleaseNotes.

## M3: Compare Tools

1. Pixel probe panel: mouse pick → RGBA/bit depth/color mode display; text copy
2. Magnifier overlay (Center/Loupe styles)
3. A-B slider view (two streams in the same region in parallel, slider switches which side shows)
4. Sync zoom/pan:
   - prefer asking 3FP for "viewport rectangle" capability (A3 confirmation);
   - otherwise UI readback + scale fallback (single-view mode only)
5. Bookmarks: frame number/time/note → CSV/JSON export
6. Difference overlay (optional, after A4 confirmation): per-pixel |ΔRGB| heatmap under identical params

**M3 add-on (ACM/wide-gamut, F24–F26)**:

7. `DisplayCapabilities` probing (DXGI output enumeration: Advanced Color/HDR/bit depth/gamut) tied to 3FP fallback events
8. Probe/difference/screenshot unified "pre-color-management" code-value path; overlay color acceptance on ACM displays

**DoD**: any stream can zoom locally and pan; probe readings accurate (tested against reference pixels); A-B slider smooth; exported bookmarks open in spreadsheet software;
SDR/HDR sessions render correctly on ACM-enabled displays; probe code values match 3FP color mode.

## M4: Engineering

1. **Secondary settings window** (SettingsDialog): hardware page / GPU selection / stepping page / window page / decode-color page / layout page (see 02 §4.5)
2. Settings storage (JSON). NativeAOT-compatible (see 06 R15): decode mode, color mode, **GPU selection, step sizes**, shortcuts, default layout, probe panel preferences
3. Session save/restore (file list + offsets + layout + current frame + loop interval)
4. Shortcut system (customizable; defaults align with common ICAT keys: Space play/pause, ←/→ frame step, Shift+←/→ second step, 1-9 switch stream, etc.)
5. Error reporting & crash logs (write local log files)
6. Auto-update check (optional; may skip for single-file release)

**DoD**: settings window can change hardware/GPU/step sizes and take effect immediately or on restart; one-click restore last session after restart; shortcuts fully customizable; logs can diagnose crashes.

3. User docs (usage guide / shortcut table / FAQ) + release notes
4. Icon/resources/localization (Chinese UI possible, following 3FP project style)
5. ACM/wide-gamut/VRR special acceptance (see 01 doc §5.1) on real HDR/VRR displays, recording results
