## 一、本次发布包含

### 1. 多路对比（ABC / ABCD）

- 2 路 → `AB`；3 路 → `AB, ABC`；≥4 路 → `AB, ABC, ABCD`，按路数自动收敛
- **快捷键 `C`** 循环切换 / 退出对比模式
- 拖动十字交叉点调整各画面占比；格表**真正驱动视频排版**（不只是覆盖层线条）
- 状态栏显示像素可信度；非 1:1 时**不会出现"像素级"字样**（硬约束）

### 2. 无缝放大

- 不用内核 `SetViewTransform`（受 `max(0,·)` 钳制不能任意平移、且为插值放大）
- 改为**放大子窗口物理尺寸**，内核按更高分辨率**真实重渲染**，平移靠移动窗口不受限
- 两道闸门：`z ≤ 4` 且总像素预算 66.4 Mpx，每次结构变化复核，超限拒绝并提示

### 3. 抓屏双线（WGC 主 + GDI 备）

- GDI 对 flip-model 不可靠（实测 7 点仅中心偶尔命中），故新增 WGC 主线路
- 原生 `3FC.WgcCapture.dll`（C++/WinRT，纯 C ABI，AOT 友好）已内嵌
- 修复 teardown 永久死锁（曾可导致宿主进程冻死）与静态内容超时

### 4. 深浅主题切换（新增）

- 入口：**设置窗口 →「外观」**，三选一：`跟随系统` / `浅色` / `深色`
- `跟随系统` 会读取并**监听** `IPlatformSettings` 的深浅色变化，系统切换时应用自动跟随
- 改选即生效（实时预览）；点「取消」会还原为进入设置前的主题
- 默认外观仍是**深色**（`ThemeVariant` 为 `null` / `Default` / 未知时一律取深色令牌）
- ⚠️ 复查重点：**自绘控件**（放大镜 `MagnifierOverlay`、差异视图 `DiffOverlayView`、
  侧栏 `ToolsSidebar`、时间轴 `TimelineView`、传输栏 `TransportBar`、分割线覆盖层
  `LayoutOverlayWindow`）在主题切换时走
  `ActualThemeVariantChanged` 重绘，**必须逐个确认无不可读文本、无残留硬编码色**
  > 2026-09-27 更新：清单里的 `AbSliderView` 已随"视图模式立成一列"撤除（它只画渐变占位、
  > 真机模式下会整块遮住真实画面），不再是复查对象。见 `docs/46 §7.7`。

### 5. 叠加模式（ICAT Single Screen，新增）

- 入口：**快捷键 `S`**（需 **≥2 路**），对应 docs/31 §2.1「阶段 2」
- 语义：两路**铺满同一区域真实叠加**（B 置顶裁半），拖动分割线平滑揭示两路差异
- 选 `S` 的依据：裸键未被占用（`Ctrl+S` 才是导出帧）、语义对上 *Single Screen*
- ⚠️ **最高风险项**：退出叠加后必须把窗口区域**完全复原**；若 `SetWindowRgn` 未清理，
  窗口会被**永久裁剪**（这是本轮唯一可能"一次性损坏会话"的路径，务必按 §三 G 组
  G21~G23 复验，见 P5）

### 6. 对比模式家族：分屏 / 网格（新增）

- 入口：**`V` = 分屏**、**`G` = 网格**（裸键，`Ctrl+V` / `Ctrl+G` 不受影响），
  或「**视图 → 对比模式**」菜单
- 与既有的 **`C` 循环**并存：`C` 仍是"进入 → 逐级切换 → 退出"的单键循环
- 按路数自动收敛：**2 路 → `AB`；3 路 → `AB, ABC`；≥4 路 → `AB, ABC, ABCD`**
- **网格模式支持 2~9 路全部显示**（`D1`~`D9` 加路）

### 7. 底栏折叠（新增）

- 入口：**`T` = 时间轴**、**`Shift+T` = 状态栏**，或「视图」菜单对应勾选项
  （勾选语义 = 面板**可见**，与折叠标志互为取反）
- 折叠后画面区变大（`DockPanel` 自动撑高，无需动画/绑定）
- 偏好落盘：**重启后折叠状态保留**
- 全屏时两栏一律不可见，但用户折叠偏好是"**暂停**"而非被覆盖，退出全屏后恢复用户选择
- 本轮修复：打开设置窗口点「确定」曾把折叠状态重置 —— 现由 `SettingsWindow` 原样回传
  （`Views/SettingsWindow.cs:90-92`），**这条要复验**

### 8. 矢量图标（新增）

- 范围：**传输栏 / 侧栏 rail / 探针面板**
- 此前用文字字形充当图标，缺字形时显示**豆腐块（□）**；现已换为矢量图标
- ⚠️ 复查重点：**图标不能是空白**，且**切到浅色主题后图标仍可见**（两件事都要看）

### 9. 浮动传输栏（新增）

- 入口：「**视图 → 浮动传输栏**」（**默认关闭**）
- 行为：鼠标靠近底部**热区**浮现、离开后**延迟隐藏**；浮条本身的浮现/隐藏**不动布局**
- 开启时传输栏从常驻布局摘走（改由 owned 顶层窗承载），常驻位让出的 54px 归视频区
- ⚠️ 复查重点：**不得高于其它应用窗口**（Owner 语义，与覆盖层层级同规）；
  以及**栏上倍速/色彩下拉能否展开**（**未实测**，见 P6 / §三 H36，本轮重点观察项）

### P1 · 多路播放间歇崩溃（既有，未修）

| 场景 | 崩溃率 |
|---|---|
| **4 路** 4K 真实播放 | **74% ~ 100%** |
| **2 路 + z=3 放大**（20.1 Mpx） | **67%** |
| 2 路 + z=2（8.9 Mpx） | 稳定 |

- 崩溃点 `dxgi.dll` 的 `CDXGISwapChain::Present`，`0xC0000005`
- ✅ **已定案（2026-09-20）**：触发者是 **RTSS / MSI Afterburner 的钩子 `RTSSHooks64.dll`**，**与本项目代码无关**。A-B-A 对照实测：

  | 条件 | 崩溃率 |
  |---|---|
  | RTSS / Afterburner **在运行** | **18/20 = 90%** |
  | **退出** RTSS / Afterburner | **0/20 = 0%** |
  | **重新启动** RTSS / Afterburner | **11/12 = 91.7%** |

  Fisher 双侧：A vs B **p = 0.0001**（两个位置均如此）；B vs A′ **p = 0.0001 / 0.0014**。
  混杂因素已排除：B 组未挂调试器、`nvspcap64` 全程仍在却不崩、位置效应已平衡、A′ 紧接 B 之后即回到 91.7%（排除时间漂移）。

- 🔧 **规避办法（推荐）**：**不必卸载 RTSS** —— 在 RTSS 里 `Add` → 选中 `3FCompare.exe` → 把 **Application detection level** 设为 **`None`**（不挂钩）即可，游戏内 OSD 不受影响。详见 `docs/33` §八。
- 若不做排除，则：4 路播放几乎必崩；**"限制在 2 路就安全"的前提不成立**——z≥3 放大在 2 路下也会崩。
- ⚠️ 已证伪的方向（勿再投入）：并发 Present（加全局锁 p=1.0）、解码负载、漂移校正 Seek、多卡争用、变换/Redraw 风暴、覆盖层 `nvspcap64`。详见 `docs/33`。

### P2 · 8K 素材放不动（环境）

`7680×4320` 能打开但 `presented` 停滞（0~23 帧）。本机解码能力不足，勿用 8K 做播放验证。

### P3 · 原生自测 67/5 flaky（未定性）

约 10% 概率，已具备取证能力（`--repeat` / 失败落盘 / `WGC_TRACE=1`）。
**该自测只人工跑，不进 CI 门禁。**

### P4 · 放大对用户可达 z≤4，但 z≥3 可能崩溃

闸门允许到 z=4，而 z=3 在 2 路下就有 67% 崩溃率。
**是否把上限收到 z≤2，待决策**（当前发布为 z≤4）。

### P5 · 叠加模式退出后窗口区域可能未复原（新增，🟠 中）

叠加模式用 `SetWindowRgn` 把窗口裁成两路铺满的形状。若**退出路径未把区域清理干净**，
窗口会被**永久裁剪**（画面缺一块，且重启前不恢复）。
发布包自测中 2/3/4 路的 `GetWindowRgn` 回读均为 `ERROR`（清理干净），
但**异常路径（崩溃 / 强制关闭 / 叠加中改路数）未覆盖**，须人工复验。

### P6 · 浮动传输栏的倍速 / 色彩下拉未实测（新增，🟡 待实测）

浮条由 **owned 顶层窗**承载，且装了命中测试钩子（子类化）以避免留白环带吞掉鼠标消息。
**栏上倍速 / 色彩两个下拉能否正常展开，本轮未实测** —— 这是浮动传输栏最可能出问题的地方，
复查时请优先看这一项（见复查记录 H 组）。

### P7 · `small.mp4` 会让探针映射断言必红（素材固有偏差，⚪）

`testmedia/media/small.mp4` 只有 **320×180**，分辨率过小会使**探针映射相关断言必然报红**。
这是**素材固有偏差，不是程序缺陷**。
⇒ 所有功能验证**必须用 `testmedia/media/real/` 下的 4K 素材**。

## 三、手动复查清单

### A. 基础（预计 3 分钟）

1. 解压后双击 `3FCompare.exe`，确认能启动、无报错
2. 打开 1 路 4K 视频，确认播放流畅
3. **按 `C`** —— 路数不足应不进入对比模式（或给出提示）

### B. 对比模式（预计 5 分钟）

4. 打开 **2 路**，按 `C` 进入 → 应看到分割线与黄色拖动手柄
5. 拖动手柄 → **画面格应跟着重排**（不只是线条动）
6. 再按 `C` → 退出，画面回到均匀网格
7. 打开 **3 路** → 可用模式应为 `AB / ABC`；**4 路** → `AB / ABC / ABCD`
8. 观察状态栏可信度显示：非 1:1 时**不应出现"像素级"字样**

### C. 覆盖层层级（本次修复重点，预计 2 分钟）

9. 在对比模式下，打开**记事本**并拖到与 3FCompare 重叠
   → 分割线应该**被记事本盖住**（修复前会浮在记事本之上）
10. 点任务栏切到记事本 → 分割线不应悬在最上层
11. 点回 3FCompare → 主窗口与覆盖层一起回来，**分割线仍高于视频画面**（这条是关键：
    既不能压住别的程序，也不能被视频盖住）
12. 最小化 → 覆盖层随之消失；还原后位置正确

### D. 抓屏（预计 3 分钟）

13. 播放中截图（F21/F20）→ 确认抓到的是**真实画面**，不是黑屏/空白
14. 日志/状态栏应显示来源为 **WGC**（若显示 GDI 说明走了兜底，需排查）

### E. 放大（**注意可能崩溃**）

15. 仅建议用 **2 路 + z≤2** 验证；z≥3 或 4 路可能触发 P1 崩溃

### F. 主题（深浅切换，预计 4 分钟）

16. 设置窗口 →「外观」→ 切到**浅色** → 界面整体变浅，**无残留深色块**
17. 逐个看**自绘控件**：放大镜、时间轴、差异视图、AB 滑杆、侧栏 rail
    → **无不可读文本**（如浅底浅字）、**无残留硬编码色**
18. 切到**深色** → 同上复看一遍（深色是默认外观，两向都要看）
19. 选**跟随系统** → 到 Windows 设置里切系统深浅色 → 应用应**自动跟随**
20. 点「取消」退出设置 → 外观应**还原**为进入设置前的主题

### G. 叠加与模式（`S` / `V` / `G`，预计 6 分钟）

21. 打开 **2 路**，按 `S` → 两路**真实叠加**在同一区域（不是并排）
22. 拖动分割线 → **平滑揭示**两路差异（画面跟着变，不只是线条动）
23. **再按 `S` 退出** → ⚠️ 窗口区域**完全复原**（这是 P5，最关键的一条）
24. 按 `V`（分屏）→ 2 路收敛到 `AB`；3 路 → `AB, ABC`；4 路 → `AB, ABC, ABCD`
25. 按 `G`（网格）→ **2~9 路全部显示**（用 `D1`~`D9` 加到 9 路验证）
26. 1 路时按 `S` / `V` / `G` → 应不进入（或提示路数不足）
27. 「视图 → 对比模式」菜单 → 与快捷键行为一致

### H. 底栏折叠与浮动传输栏（`T` / `Shift+T`，预计 5 分钟）

28. 按 `T` → 时间轴折叠，**画面区变大**
29. 按 `Shift+T` → 状态栏折叠，画面区再变大
30. **重启程序** → 折叠状态**保留**
31. 折叠状态下打开设置窗口点「**确定**」→ 折叠状态**不丢失**（⚠️ 本轮修过的 bug，必验）
32. 「视图」菜单里两项的**勾选**与折叠状态一致（勾上 = 可见）
33. 「视图 → 浮动传输栏」开启 → 鼠标靠近底部**浮现**、离开后**延迟隐藏**
34. ⚠️ 浮条**不得高于其它应用窗口**（打开记事本拖到重叠，浮条应被盖住）
35. ⚠️ **重点**：点浮条上的**倍速 / 色彩下拉** → **能否展开**（未实测，见 P6）

### I. 矢量图标（预计 3 分钟）

36. 看**传输栏 / 侧栏 rail / 探针面板**的图标 → **不能是空白**、不能是 `□`（豆腐块）
37. 切到**浅色主题** → 图标**仍可见**（不能浅底浅图标消失）
38. 图标随窗口缩放 / DPI 变化不糊、不错位
